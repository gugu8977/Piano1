# 🎵 동요 리듬 놀이 (Piano1)

유아와 초보자가 익숙한 동요를 피아노 건반으로 따라 치며 박자 감각을 익히는 웹/안드로이드 게임입니다.
위에서 내려오는 음표 블록이 주황색 판정선에 닿을 때 같은 색 건반을 누르면, 정확도에 따라 점수와 고양이 캐릭터가 반응합니다.

## 기능

| 구분 | 내용 |
|---|---|
| 곡 | 쉬움/보통/어려움 11곡 (저작권이 끝난 전래·고전 곡) + 직접 만드는 **내 노래** |
| 화면 | 🎹 내려오는 음표 · 🎼 악보-진행선 이동 (다 친 마디 자리에 다음 마디가 미리 나타남) · 🎼 흐르는 악보 (진행선 고정, 악보가 왼쪽으로 흐름) |
| 메인 메뉴 | 🎮 박자 게임 · 🐣 기다려 주기 · 🎹 자유 연습 · 🗓 스티커 · ⚙ 설정 (설정·스티커는 어느 화면에서든 오른쪽 위 버튼으로) |
| 놀이 방법 | 🎮 박자 게임 (타이밍 판정) · 🐣 기다려 주기 (맞는 건반을 누를 때까지 대기) · 👀 보고 듣기 (시범 연주) · 🎹 자유 연습 (1~4옥타브 건반, 시작 높이 선택, 누른 음이 색 방울로 표시) |
| 악기 | 🎹 피아노 · 🔔 실로폰 · 🎶 오르골 · 🥁 드럼 (Web Audio로 합성, 음원 파일 없음) |
| 도움 기능 | 다음 건반 미리 빛내기, 시작 전 4-3-2-1, 박자 드럼(켬/끔), 마디선, 진행 막대 |
| 조절 | 빠르기(느리게/보통/빠르게), 판정 너그러움, 타이밍 보정(블루투스 이어폰용), 건반 글자(도레미/CDE/없음) |
| 기록 | 곡·모드별 최고 정확도와 별(⭐) 저장, 결과 창, 콤보, 축하 효과 |
| 악보 | 높은음자리표, 박자표, 마디를 넘는 음은 붙임줄, 한 박 안의 8분음표 두 개는 막대로 묶음, 쉼표·점음표·♭ |
| 연습 | 구간 연습(시작~끝 마디 선택), 🔁 구간 반복(85% 이상이면 10%씩 빨라짐, 최대 1.5배), 틀린 건반을 누르면 맞는 건반 깜빡임과 이름 안내, 다음 건반 옆을 살짝 벗어나 눌러도 인정(판정 너그러움에 따라 범위 조절) |
| 동기 부여 | 🗓 스티커 달력(하루 한 곡 끝내면 스티커, 연속 일수), 🔒 곡 잠금(쉬움 곡은 열림, 앞 곡 ⭐⭐⭐이면 다음 곡 열림 · 설정에서 끌 수 있음) |
| 조작 | 멈춤/계속(앱 전환 시 자동 멈춤), 처음으로, PC 키보드 `A S D F G H J K`(흰건반) · `W E T Y U`(검은건반), 드럼은 스페이스바 |

설정과 기록, 내 노래는 기기(localStorage)에만 저장됩니다.

## 구조

```
www/index.html     게임 전체 (HTML/CSS/JS 한 파일, 외부 라이브러리 없음)
android/           Capacitor로 만든 안드로이드 프로젝트 (가로 고정, 전체화면, 화면 꺼짐 방지)
capacitor.config.json
```

### 곡 추가하기

`www/index.html`의 `SONGS`에 한 줄을 추가합니다.

```js
"곡 이름": {lv:1, bpm:90, n:"C C G G A A G2"},
```

- 음이름: `C D E F G A B`, 높은 도는 소문자 `c`, 반음은 `F#`·`Bb`처럼 뒤에 `#`/`b`
- 음 뒤 숫자는 박자 수 (생략하면 1, `.5`는 반 박)
- `lv`: 1 쉬움, 2 보통, 3 어려움 / `m`: 한 마디 박자 수 (생략하면 4)

곡을 추가한 뒤 `npm test`로 모든 음이 건반에 있는지 검사할 수 있습니다.

앱 안의 **⚙ 설정 → ✏️ 내 노래 만들기**에서 건반을 눌러 곡을 만들 수도 있습니다.

## 실행

- **PC 브라우저**: `www/index.html`을 열면 됩니다.
- **안드로이드**: 필요 도구는 Node.js, JDK 21, Android SDK(`ANDROID_HOME`)입니다.

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug    # APK: android/app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug     # USB 디버깅으로 연결된 폰에 바로 설치
```
